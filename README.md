# MyDisciplineApp

Mobile application built with **React Native** and **Expo** to help users track daily habits and stay consistent with their goals.

## 🚀 Features
* **Habit Tracking:** Easy-to-use interface for managing daily tasks and goals.
* **Progress Analytics:** Visual progress trackers and completion streaks.
* **Cross-Platform:** Smooth performance on both iOS and Android.

## 🛠️ Tech Stack
* **Framework:** React Native (Expo)
* **Language:** TypeScript / JavaScript
* **UI & Styling:** Clean, responsive UI components
* **Version Control:** Git & GitHub
